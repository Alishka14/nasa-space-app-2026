# EARTH SENSES — Interconnected Earth Intelligence

**NASA Space Apps Challenge 2026 · Challenge: _Be An Earth System Trend Detective!_**

> We don't just visualize Earth's changes. We investigate their relationships, challenge our assumptions, and preserve the evidence.
>
> **AI proposes. Evidence decides. Earth Senses investigates.**

EARTH SENSES is a tool for finding out what is changing in the Earth system at a chosen place, how fast, whether the
change is statistically significant, which variables change together, and — just as important — what the data cannot
tell you. Every result is an **evidence record** that can be recomputed from a raw NASA file identified by its SHA-256.
No language model takes part in any calculation.

## What it answers

| Question | Where in the tool |
|---|---|
| What is changing? Where? How fast? | Trend cards: Theil–Sen slope per year with a 95% confidence interval, for the chosen point and period |
| Is it significant? | Two autocorrelation-aware tests that must agree, plus false-discovery correction across variables |
| What changes together? | Relationship cards and the evidence-backed relationship graph |
| Does the link survive removing the seasonal cycle? | Correlation shown four ways: raw, seasonal cycles alone, deseasonalized, detrended |
| Does it survive holding a third variable fixed? | Partial correlations for every pair |
| Is the link true by definition? | ⚙ *built-in dependence* flag where one variable is computed from the other, with a check that measures it |
| Is there a time lag? | Lag scan, ±6 months, corrected for the number of lags tried |
| Does the result survive a change of period? | Sub-period heatmap, leave-one-year-out, automatic comparison with the longer record |
| Which hypotheses do the observations contradict? | Counterevidence in every record; the Evidence Timeline shows each revision |
| What cannot be concluded? | A dedicated list in every investigation and report |

## The Pavlodar case in five lines

NASA POWER / MERRA-2, 52.29°N 76.97°E, 2001–2024. Full details: [`docs/GEMINI_REPRODUCTION.md`](docs/GEMINI_REPRODUCTION.md).

- All 16 numbers reported by Gemini were reproduced at their reported precision from separately retrieved data
  (the trend method was not stated and had to be inferred; the comparison was not blind).
- Raw temperature–humidity correlation is −0.95, but −0.98 comes from the two seasonal cycles alone; between anomalies it is −0.32.
- Precipitation–humidity changes sign when the seasonal cycle is removed: −0.28 raw, +0.59 between anomalies. It
  stays at +0.59 with temperature held fixed and +0.44 with temperature and specific humidity held fixed; it is absent
  in winter (−0.06) and +0.37 when every calendar month is weighted equally.
- Relative humidity is computed by NASA POWER from temperature, specific humidity and pressure. Rebuilt with a
  textbook formula it matches the NASA values at r = 0.98, so the temperature–humidity edge is flagged as partly
  built into the definition.
- Temperature: no significant trend, and no basis for saying "no warming": the 95% interval is −0.67 to +0.46 °C per decade.
- Humidity: +0.16 percentage points per year with p = 0.035, but q = 0.105 after correction, the result flips when single
  years are left out, and it disappears over 1981–2024. Verdict: fragile, not established.

## First screen: onboarding

On the first visit the app opens with a short onboarding over a real WebGL Earth: splash → language
(English, Русский, Қазақша) → an intro film → the app. Three intro lengths, each in three languages:
Short (16.5 s), Explainer (45 s), Full film (59.5 s). The story is the project's main finding —
precipitation–humidity −0.285 raw, +0.593 with the seasonal cycle removed — and every number on screen is
computed by the engine (`scripts/build_intro_assets.py`) and checked by `backend/tests/test_09_intro_content.py`.

- Returning visitors go straight to the app; **▶ Intro** in the header plays it again, **EN | RU | KZ** switches
  the language. `?intro` forces the onboarding, `?nointro` skips it.
- Design and implementation: [`docs/visual/`](docs/visual/) · scripts, storyboards and subtitles for all nine
  versions: [`docs/video/VIDEO_MASTER_PLAN.md`](docs/video/VIDEO_MASTER_PLAN.md).
- Silent by design (narration shown as subtitles). Earth imagery: NASA Earth Observatory (Blue Marble: Next
  Generation; Earth at Night 2012) — provenance and credits in
  [`docs/visual/ASSETS_AND_LICENSES.md`](docs/visual/ASSETS_AND_LICENSES.md).
- Recorded films (1920×1080, screen captures of the app): [`docs/video/renders/MANIFEST.md`](docs/video/renders/MANIFEST.md).

## Run it

Requirements: Python 3.13, Node 22.

```bash
# backend
python -m venv .venv && source .venv/bin/activate
pip install -r backend/requirements-dev.txt
python scripts/build_provenance.py                 # re-verifies the SHA-256 of every raw NASA file (4 × OK)
(cd backend && python -m pytest)                   # 175 tests
uvicorn earth_senses.api:app --app-dir backend --port 8000

# frontend (second terminal)
cd frontend && npm install && npm run dev          # http://localhost:5173, proxies /api to :8000
```

Single process for a demo: `cd frontend && npm run build`, then start `uvicorn` as above and open
<http://localhost:8000>. API documentation: <http://localhost:8000/docs>.

`EARTH_SENSES_OFFLINE=1` makes the backend serve only the verified bundled files. Without it, a place or period that is
not bundled is requested live from NASA POWER, validated, stored verbatim with a provenance record, and then analysed.
If neither route can supply the data the API returns an error; it never substitutes invented values.

Regenerate the documents that are computed: `python scripts/reproduce_gemini.py`, `python scripts/build_docs.py`
and `python scripts/science_review.py`.

**Two-minute check after cloning** (no internet needed once the packages are installed):

1. `python scripts/build_provenance.py` prints `OK` four times.
2. `(cd backend && python -m pytest)` ends with `175 passed`.
3. `(cd frontend && npm ci && npm run build)`, then
   `EARTH_SENSES_OFFLINE=1 uvicorn earth_senses.api:app --app-dir backend --port 8000`.
4. Open <http://localhost:8000>, press **Investigate**: Pavlodar 2001–2024 appears from the bundled NASA files.
   Scroll to *Precipitation ↔ Relative humidity* (−0.28 raw, +0.59 with the seasons removed) and press
   **View evidence →**.

## Data

| | |
|---|---|
| Source used | NASA POWER Monthly & Annual API v2.10.0 (NASA Langley Research Center) |
| Underlying product | MERRA-2 reanalysis (NASA GMAO): `T2M`, `RH2M`, `PRECTOTCORR`, `QV2M` |
| Kind | Model reanalysis that assimilates satellite and conventional observations; not a direct measurement |
| Resolution | 0.5° × 0.625° grid cell, monthly means |
| Bundled | Pavlodar 1981–2000 and 2001–2024 (three variables), Pavlodar 2001–2024 specific humidity; Almaty grid cell 2001–2024 |

**Eligibility and independent sources.** The 2026 Project Submission Guide asks for at least one NASA data set or
resource; NASA POWER / MERRA-2 is one. The challenge's Resources tab also lists Giovanni, Hydrology Time Series,
AppEEARS and NOAA Climate Data Online; none of those has been used. We tried to add satellite precipitation as an
independent check: NASA POWER accepts the parameter `IMERG_PRECTOT`, but for the Pavlodar point it returned its
missing-value code for every month of 2001–2024. That response is stored with its hash and the tool refuses to analyse
it. The Giovanni time-series service was not reachable from the build environment (**NOT RUN**). So every variable
still comes from one model; see [`docs/KNOWN_LIMITATIONS.md`](docs/KNOWN_LIMITATIONS.md).
