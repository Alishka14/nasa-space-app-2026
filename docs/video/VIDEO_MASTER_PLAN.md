The in-app intro, these documents and the subtitles are produced from one file, `frontend/src/onboarding/content/intro-scripts.json`; the numbers from `facts.json`, which `scripts/build_intro_assets.py` computes with the engine from the hash-verified NASA files.

## Story every version keeps

1. Earth as one interconnected system.
2. Data can mislead when read naively.
3. Seasonality changes the relationship: precipitation–humidity −0.285 raw, +0.593 with the seasonal cycle removed (Pavlodar grid cell, 2001–2024).
4. EARTH SENSES checks the evidence (seasonality, autocorrelation, multiple tests, other periods).
5. Correlation is not causation.
6. Uncertainty and limits are kept: “no warming” is not supported; “humidity is rising” is fragile.
7. The viewer enters the application.

## What the films must not say

- that a causal relation is proven;
- that there is no warming;
- that humidity is definitely rising;
- that the atmosphere has no memory;
- anything about a city or region beyond one MERRA-2 grid cell.

Checked automatically: `backend/tests/test_09_intro_content.py` runs every English and Russian line through the MIZAN Guard (Kazakh is not covered by the guard), checks every number against the engine, every placeholder, every duration and every reading speed.

## How to record a version from the app

```bash
EARTH_SENSES_OFFLINE=1 uvicorn earth_senses.api:app --app-dir backend --port 8000
# open http://localhost:8000/?capture&variant=teaser&lang=en  (no controls, clock driven by window.__esIntro.seek)
SCALE=1.5 node scripts/record_intro.mjs teaser en   # frame-exact capture, 1920×1080 -> docs/video/renders/teaser_en.mp4
python scripts/package_videos.py                    # metadata, decode check, renders/MANIFEST.md
bash scripts/make_demo.sh                           # 30-second English demo -> renders/demo_en.mp4
```

Live playback (with controls): <http://localhost:8000/?intro>. Choose the language and the length on the second screen. Keys: Space pause, R replay, C subtitles, Esc skip.
